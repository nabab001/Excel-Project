Bike Buyer Analysis (Excel Data Cleaning & Dashboard Project)
Problem

The raw customer data was messy and difficult to use for analysis.
It contained blank values, inconsistent formats, and no clear way to identify which customer segments were more likely to buy a bike.

The goal was to clean the data and turn it into clear insights that could help identify potential bike buyers.

What I Did
1. Data Cleaning
   
   Removed blank and inconsistent values

   Standardized column formats

   Ensured the dataset was clean, structured, and ready for analysis

2. Data Preparation

  Created new features such as Age Bracket to simplify analysis

  Organized the dataset into a clear, analysis-ready structure

3. Analysis

  Built pivot tables to analyze bike purchases by:

      Age group

    Education level

    Commute distance
  Compared average income across different customer segments

4. Dashboard Creation

  Designed a simple Excel dashboard using charts and summary tables

  Highlighted key patterns and customer segments visually

  Made insights easy to understand for non-technical users

Tools Used

    Microsoft Excel

    Pivot Tables

    Charts & Data Visualization

Final Output

  The final deliverables include:

  A cleaned Excel dataset ready for analysis

  Pivot tables summarizing customer behavior

  A clear, easy-to-understand Excel dashboard showing:

    Which customer groups are more likely to buy bikes

    How income and commute distance relate to purchasing decisions


Key Insight

  Middle-aged customers with higher income and shorter commute distances showed a higher likelihood of purchasing bikes.
