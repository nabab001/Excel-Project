Bike Buyer Analysis Project
1. Data Files
bike_buyers.csv: The raw source data containing customer demographics, income, and purchase records.

Working Sheet.csv: The cleaned and enhanced dataset. Includes data cleaning (handling blanks) and feature engineering (e.g., creating the Age Bracket column).

2. Analysis & Output
Pivot Table.csv: Houses summary data used for analysis, including purchase counts by demographics (Age, Education, Commute Distance) and average income comparisons.

Dashboard.csv: The final deliverable—a visual, interactive dashboard summarizing key findings to identify target customer segments most likely to purchase a bike.
